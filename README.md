# Домашнее задание: Классы Product и Category на Python

## Описание проекта

В этом проекте реализованы два класса:

- **Product** — описывает товар с атрибутами:
  - `name` (название)
  - `description` (описание)
  - `price` (цена, с копейками)
  - `quantity` (количество в наличии)

- **Category** — описывает категорию товаров с атрибутами:
  - `name` (название категории)
  - `description` (описание)
  - `products` (список объектов Product)

Класс **Category** содержит также два атрибута класса для подсчёта:

- `category_count` — общее количество созданных категорий
- `product_count` — общее количество товаров во всех категориях

Атрибуты автоматически обновляются при создании новых объектов.

## Тестирование

Проект включает набор тестов с использованием `pytest`, которые проверяют:

- корректность инициализации объектов классов
- подсчёт общего количества категорий и товаров

Покрытие тестами составляет более 75%.

## Запуск проекта

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Запустите тесты:

```bash
pytest --cov=. --cov-report=term-missing
```

3. Для демонстрации работы классов запустите `main.py`:

```bash
python main.py
```
