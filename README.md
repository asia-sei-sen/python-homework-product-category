## Описание проекта

В этом проекте реализованы два класса:

- **Product** — описывает товар с атрибутами:  
  - `name` (название)  
  - `description` (описание)  
  - `price` (цена, с копейками)  
  - `quantity` (количество в наличии)

- **Category** — описывает категорию товаров с атрибутами:  
  - `name` (название категории)  
  - `description` (описание)  
  - `products` (список объектов Product)

Класс **Category** содержит также два атрибута класса для подсчёта:

- `total_categories` — общее количество созданных категорий  
- `total_products` — общее количество товаров во всех категориях

Атрибуты автоматически обновляются при создании новых объектов.

## Новые возможности

- Переопределены методы строкового представления объектов (`__str__`):  
  - **Product**: выводит строку вида  
    `Название продукта, X руб. Остаток: X шт.`  
  - **Category**: выводит строку вида  
    `Название категории, количество продуктов: X шт.`

- Реализован магический метод сложения (`__add__`) для класса **Product**:  
  - Складывает полную стоимость двух товаров (цена × количество).  
  - Позволяет складывать только объекты одного класса, иначе выбрасывает `TypeError`.

- Добавлены классы-наследники от `Product`:  
  - **Smartphone** с атрибутами: `efficiency`, `model`, `memory`, `color`  
  - **LawnGrass** с атрибутами: `country`, `germination_period`, `color`

- В метод добавления продукта в категорию (`add_product`) добавлена проверка, разрешающая добавлять только объекты класса `Product` или его наследников (используются `isinstance()`).

- Добавлен абстрактный класс `BaseProduct`, который задаёт общую структуру и поведение для всех продуктов.

- Класс `Product` теперь наследуется от `BaseProduct` и миксина `LogMixin`.

- Миксин `LogMixin` при создании объекта выводит в консоль информацию о классе и параметрах инициализации.

- Реализована проверка при создании товара: если количество равно нулю — выбрасывается исключение `ValueError` с сообщением «Товар с нулевым количеством не может быть добавлен».

- В классе `Category` добавлен метод `average_price()`, который вычисляет среднюю цену товаров в категории с обработкой случая, когда товаров нет (возвращает 0).
