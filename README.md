## Описание проекта

В этом проекте реализованы два класса:

- **Product** — описывает товар с атрибутами:
  - `name` (название)
  - `description` (описание)
  - `price` (цена, с копейками)
  - `quantity` (количество в наличии)

- **Category** — описывает категорию товаров с атрибутами:
  - `name` (название категории)
  - `description` (описание)
  - `products` (список объектов Product)

Класс **Category** содержит также два атрибута класса для подсчёта:

- `category_count` — общее количество созданных категорий  
- `product_count` — общее количество товаров во всех категориях

Атрибуты автоматически обновляются при создании новых объектов.

## Новые возможности

- Переопределены методы строкового представления объектов (`__str__`):
  - **Product**: выводит строку вида  
    `Название продукта, X руб. Остаток: X шт.`
  - **Category**: выводит строку вида  
    `Название категории, количество продуктов: X шт.`

- Реализован магический метод сложения (`__add__`) для класса **Product**:
  - Складывает полную стоимость двух товаров (цена × количество).

- Добавлены классы-наследники от `Product`:  
  - **Smartphone** с атрибутами: `efficiency`, `model`, `memory`, `color`  
  - **LawnGrass** с атрибутами: `country`, `germination_period`, `color`

- Переопределены методы строкового представления объектов (`__str__`):  
  - **Product**: выводит строку вида  
    `Название продукта, X руб. Остаток: X шт.`  
  - **Category**: выводит строку вида  
    `Название категории, количество продуктов: X шт.`

- Реализован магический метод сложения (`__add__`) для класса **Product** и наследников:  
  - Складывает полную стоимость двух товаров (цена × количество)  
  - Позволяет складывать только объекты одного класса, иначе выбрасывает `TypeError`

- В метод добавления продукта в категорию (`add_product`) добавлена проверка, разрешающая добавлять только объекты класса `Product` или его наследников. Используются функции `isinstance()` и `issubclass()`.
